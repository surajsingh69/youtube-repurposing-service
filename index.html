How It Works

  1. Get a transcript — Use the Python script to fetch a YouTube transcript, or paste an existing transcript.
  2. Paste it here — The browser tool processes the text locally.
  3. Generate outputs — Click to create a summary, blog draft, thread, quotes, or all at once.
  4. Copy or download — Use the outputs as starting drafts. Review and edit before publishing.

Privacy

This tool runs entirely in your browser using JavaScript. No transcript text, URLs, or generated content is sent to any server. No data is stored. You can disconnect from the internet after the page loads and it will still work.
