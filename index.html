The toolkit takes a YouTube video URL and produces structured content from the available public transcript.

Blog Draft

A structured draft article with an overview, key points, discussion, and conclusion extracted from the transcript.

Social Thread Draft

A draft Twitter/X thread selected from the transcript, formatted as individual posts.

Candidate Quotes

Extracted quotable sentences from the transcript, formatted for social media or newsletters.

Summary

A condensed summary of the video's main ideas, drawn from the transcript.

Cleaned Transcript

How to Use the Free Toolkit

  1. Download the Python script — Get the single-file toolkit from this site.
  2. Install the dependency — Run pip install youtube-transcript-api in your Python environment.
  3. Run the script — Execute python youtube_repurposer.py "YOUR_VIDEO_URL"
  4. Get your files — The toolkit creates a folder with blog draft, thread draft, quotes, summary, cleaned transcript, and warnings.
  5. Edit and use — All outputs are automated first drafts. Review and edit before publishing.

Example Command

python youtube_repurposer.py "https://www.youtube.com/watch?v=aircAruvnKk"

Output: blog_post.md, twitter_thread.md, key_quotes.md, summary.md, transcript.txt, warnings.txt

Limitations & Honest Expectations

  • Transcript availability: This toolkit only works with videos that have public transcripts. Some videos disable transcripts or have poor auto-generated text.
  • Automated drafts: Output is generated by rule-based algorithms, not advanced AI. Blog drafts, threads, and summaries may need substantial editing before publication.
  • No word-count guarantees: Draft length varies by transcript length and content. We do not guarantee specific word counts or "professional" finished quality.
  • No fixed turnaround: Processing speed depends on your computer and the video's transcript length. There are no guaranteed delivery times.
  • No human editing: Human review and editing are not included. You are responsible for reviewing and refining all outputs.
  • Copyright: You are responsible for ensuring you have the right to repurpose any video content. The toolkit flags music and copyright indicators for your review.
