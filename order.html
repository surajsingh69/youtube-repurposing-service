Download the Free YouTube Toolkit

Get Started in 3 Steps

The toolkit is a single Python script. Download it, install one dependency, and run it on your computer.

Step 1: Download the Script

Download youtube_repurposer.py from the project repository or copy it from the project folder.

Step 2: Install the Dependency

Open a terminal and run:

pip install youtube-transcript-api

If you use a virtual environment, activate it first.

Step 3: Run the Toolkit

Execute the script with a YouTube video URL:

python youtube_repurposer.py "https://www.youtube.com/watch?v=VIDEO_ID"

Replace VIDEO_ID with the actual video ID. The toolkit creates an output folder with all generated files.

What You Get

  • blog_post.md — Structured blog draft
  • twitter_thread.md — Draft Twitter/X thread
  • key_quotes.md — Candidate quotes from the transcript
  • summary.md — Condensed video summary
  • transcript.txt — Cleaned full transcript
  • warnings.txt — Any content warnings or issues

Important

This toolkit only works with videos that have public transcripts. Some videos disable transcripts or have poor auto-generated text. Output is automated and may require editing before publication. Human editing is not included.

Privacy & Data Handling

  • Website processing: This site does not receive, upload, or store transcripts, video content, or generated outputs. The website form only validates the URL format and tracks daily usage locally.
  • Local processing only: All transcript extraction and content generation happens on your computer via the Python script. No data is sent to external servers.
  • Stored data: Daily usage limits are tracked in your browser's localStorage. No URLs, transcripts, or personal information are stored on any server.
  • Limitations: This is a static site with no backend. Usage limits are client-side only. Do not use this toolkit with videos you do not have rights to repurpose.
