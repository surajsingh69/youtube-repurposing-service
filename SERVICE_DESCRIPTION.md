# YouTube Content Repurposing Toolkit

## What This Toolkit Offers

A free, downloadable Python script that turns YouTube videos into multiple structured content drafts:

- **Blog Drafts** — Draft articles with overview, key points, and sections
- **Twitter/X Thread Drafts** — Draft tweets selected from video content
- **Key Quotes** — Notable quotes extracted from the transcript
- **Summaries** — Condensed summaries drawn from the video transcript
- **Cleaned Transcripts** — Full text with artifacts removed

## Who This Is For

- Content creators who want to repurpose long-form YouTube content
- Social media managers needing quick Twitter threads from videos
- Bloggers looking for content ideas from video sources
- Students/researchers extracting key points from educational videos
- Podcasters turning interviews into written content

## Pricing

This toolkit is completely free. No payments, no subscriptions, no paid upgrades.

## How to Use

1. Download the Python script from the project repository
2. Install the dependency: `pip install youtube-transcript-api`
3. Run the script: `python youtube_repurposer.py "YOUR_VIDEO_URL"`
4. Find your generated files in the output folder
5. Edit and refine the drafts as needed

## Example Output

**Input:** 20-minute YouTube tutorial on machine learning
**Output:**
- Blog draft with sections
- Twitter/X thread draft
- Key quotes from the transcript
- Condensed summary
- Cleaned transcript
- Content warnings
